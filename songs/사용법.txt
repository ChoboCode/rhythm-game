이 폴더에 음악 파일을 넣습니다.

1) mp3 · wav · ogg · m4a 파일을 이 폴더에 복사합니다. 파일명 끝에는 _분_초를 붙입니다(예: 내 첫 곡_3_12.mp3).
2) songs.json 을 열어 아래처럼 목록에 적습니다.

[
  { "title": "내 첫 곡", "artist": "Suno", "file": "내 첫 곡_3_12.mp3", "duration": 192.5,
    "charts": { "easy": "내 첫 곡_3_12.easy.json", "normal": "내 첫 곡_3_12.normal.json", "hard": "내 첫 곡_3_12.hard.json" } },
  { "title": "두 번째 곡", "file": "두 번째 곡_2_45.mp3", "duration": 165.2,
    "charts": { "easy": "두 번째 곡_2_45.easy.json", "normal": "두 번째 곡_2_45.normal.json", "hard": "두 번째 곡_2_45.hard.json" } }
]

- 목록에 등록한 곡은 EASY/NORMAL/HARD 저장 채보가 모두 필요합니다.
  파일이 없거나 손상되면 게임은 오류를 표시하고 자동 채보로 대체하지 않습니다.
- 새 곡은 채보를 미리 만든 다음 음원을 들으며 타이밍과 노트 배치를 검토하고 등록하세요.
  직접 연 파일은 결과 화면의 [채보 파일로 저장] 으로 채보를 내려받을 수 있습니다.
- "key" 는 곡 정보에 표시할 조성입니다. 노트를 맞히면 짧은 드럼 효과음이 납니다.
  채보 노트에 "drum" 값을 kick, snare, hat, crash, tom 중 하나로 적으면 그 소리가 나고,
  없으면 레인 위치에 따라 타악기 소리를 고릅니다.
- 곡 이미지가 생기면 이 폴더에 넣고 songs.json 항목에 "cover": "표지.png"를
  적으면 연주 화면의 디스크에 표시됩니다. 이미지를 적지 않으면 기본 디스크가 나옵니다.
- 서버로 실행한 뒤 등록 곡을 선택하면 해당 난이도의 저장 채보만 사용됩니다.
- 다른 곡의 기본 자동 채보는 node tools/build-song-charts.cjs "songs/곡.mp3" --write
  로 만들 수 있습니다. 목록에 쓰려면 songs.json 의 "charts"에 난이도별 파일명을 적습니다.
  이 명령을 "우리 마을 축제"에 실행하면 기존 드럼 중심 채보를 덮어쓰므로 주의하세요.
- 새 음원을 등록한 뒤 rhythm-game 폴더에서 node tools/test-song-library.cjs 를
  실행하면 누락된 음원·표지·채보와 겹치는 레인을 확인할 수 있습니다.

주의: 이 목록은 웹 서버로 열었을 때만 읽힙니다.
index.html 을 파일로 바로 열면 브라우저가 폴더 접근을 막으므로,
그 경우에는 게임 화면에서 [내 음악 파일 열기] 로 고르거나 끌어다 놓으세요.
